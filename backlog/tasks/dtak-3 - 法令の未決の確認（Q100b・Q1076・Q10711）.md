## Implementation Notes

2026-11-16 サブエージェント調査（事実の収集のみ。法的判断ではない）。
[snow の cacophony.txt] 上流 centromere/cacophony（Unlicense）とバイト一致。snow 側は Apache-2.0 OR MIT。GPL 互換。条件つきで可（出典・コミット・sha256 を記し、MIT を選ぶなら表示を同梱）。試験のときに取る運用なら、リポジトリに入れない現状のままでよい。
[HPKE test-vectors.json] 独自のライセンス文なし。CONTRIBUTING が IETF の規則を指すのみ。IRTF 資料に BSD が及ぶか確認できず。入れない運用を続ける。
[RFC の例の値] 5869・6238 は TLP 4.0 で、Code Component は BSD。Appendix B など値の表が Code Component か未確認。7748・8032 は IRTF の TLP 5.0 で、§8.g により BSD は適用されず、確認できなかった。数値の事実は著作権が薄いとされるが、本件への当てはめは未判断。
置き換えが必要かは利用者の判断待ち。

2026-11-16 利用者の決定: RFC 7748・8032・5869・6238 の例の値を置き換える。CryptoTest・TotpTest・InvitationTest の値を、乱数から作って Python の cryptography・hmac・hashlib（独立した実装）で計算した値に置き換えた。テスト名から Rfc を外した。核 1,180 件が通る。TPP（tak.gov/user_builds）は使えることを確認済み、TPC（TAK Product Center）の認証は将来のタスクと決まり、CLAUDE.md・docs/README.md・docs/01-requirements.md・plugin/README.md を直した。Q100(b)・Q107(6)・Q107(11) の判断を PRC-163:docs/legal.md に書くのは、利用者の確認のあと（AC #1 は未了）。
