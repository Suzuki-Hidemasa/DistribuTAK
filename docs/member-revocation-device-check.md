# メンバー取り消しと鍵の入れ替えの実機確認

実行するのは、利用者の許可を受けた利用者かオーケストレーターです。作業者とレビュアーは端末を操作しません。対象はS20とXperia 1です。

## 実行前に止めて確認すること

この手順は、片方の所属を取り消します。取り消された側は同じ身元では戻れず、最後の知らせを受けた場合は自動で消去されます。2026-12-03ごろまでの消去・グループの作り直し・新しい招待の禁止に関わるため、現在の2台で実施してよい時期と、自動消去を伴う試験の許可を先に利用者へ確認します。許可が出るまで実行しません。

両端末の既存の所属を保ち、保存の移行と形式2への証明書更新を済ませます。第7回のAPKは入れません。試験する版は、PCの全試験とlintを通し、利用者かオーケストレーターが承認した版に限ります。インストールも別途許可を得て行います。アンインストール、アプリのデータ消去、権限変更、ATAKの保存領域への書き込みは行いません。

## 確認の順序

1. 両端末を同じWi-Fiへつなぎます。両方の画面で接続を確かめ、残す側が管理者であること、取り消す側が一般メンバーであることを確かめます。取り消す側が管理者なら、別の確認操作で先に管理者から外します。最後の管理者は外せません。
2. 残す側で「呼び名を付ける」を開き、対象の本人だけに「通信を止める」から「接続する」を押してもらいます。接続し直した候補が1件だけであることを確認し、呼び名を入力して保存します。短い切断は観測できない場合があるため、確認へ進まなければ切断と接続をやり直します。複数候補ならやり直します。この操作は、暗号で本人の身元を保証するものではありません。
3. 残す側で「メンバーを取り消す」を押し、端末内の呼び名で相手を選びます。確認画面の対象、鍵の入れ替えが必ず伴うこと、同じ身元では戻れないことを本人と確認してから進めます。
4. 残す側で、取り消しと鍵の入れ替えの完了を確認します。呼び名の一覧から対象が消えたことを確かめます。残す側の所属と管理権限が保たれ、通信が停止状態になっていないことも確認します。
5. 取り消した側が新しいグループの鍵を受け取れないことを確認します。最後の知らせが届いた場合は、理由の表示と自動消去も確認します。知らせが届かない場合は、自動消去と理由表示を成功の必須条件にしません。
6. 取り消しの確定から180秒を超えて待ちます。取り消した側から再接続を試し、残す側が接続を受け付けず、グループの通信が再開しないことを確認します。自動消去済みの場合は、未所属のままであることを確認します。新しい招待や復帰操作は行いません。
7. 必要に応じて利用者かオーケストレーターがアプリを再起動し、残す側で取り消しと呼び名の削除が保存されていること、取り消した側が再接続できないことを再確認します。端末のデータは消しません。

## 記録と機微値の検査

記録するのは、試験の版の呼称、項目ごとの成否、件数、種類だけです。呼び名、秘密、通信先、本人や端末を識別する値は記録しません。画面の撮影や生のログの貼り付けは行いません。

ログを見る必要がある場合も、操作する人が端末を明示します。コマンドの形は `adb -s <端末の識別子> logcat` とし、実際の指定値をこの文書や報告へ転記しません。許可された場所で目視し、鍵・招待・TOTP・PSK・呼び名・本人や端末の識別に使う値が出ていないかを確かめ、種類と件数だけを残します。

PCの試験だけでは、実機での取り消し後の接続拒否や実機ログの検査を完了とはしません。未実行の項目は未実行と報告します。復帰には新しい身元と招待が必要です。復帰を含む追加操作は、利用者の許可が出るまで行いません。
