# 保存形式6への移行

版2〜5の保存は消去せず読み込みます。読み込みだけではstateの形式を変えず、通常通信を開く前に停止印の固定領域を確保します。次の保存成功で版6へ進みます。身元・握手・管理者・グループの各鍵、証明書、保存相手、更新待ち、保存と発見の番号、同期の初期化状態を保ちます。同期の記録と外来の印も引き継ぎます。

版6を一度保存した端末では、版5までの旧APKへ戻さないでください。旧APKは版6と管理ファイルを読めません。互換性のために保存を消したり、グループを作り直したりする手順は設けません。

更新後は通常の起動と保存で移行します。「保存がいっぱい」で止まった場合は記録を消さず、空きを作って起動し直します。第7回では保存の復旧を扱う口までを実装しており、相手から一覧を取り直す製品の通信は第8回に追加します。再起動だけで直るとは保証しません。印や管理ファイルが壊れている場合も、古い世代を探して自動復元しません。

**第8回がマージされるまで、第7回のAPKを実機へ入れないでください。** 受信した失効の一覧を保存できず（履歴の件数・バイト数、または管理平文の上限を超えた場合）、「候補なし」の停止印（全ゼロの目標）を確定した場合、第7回の実装には、その停止を解く経路がありません。解く条件（取り直した一覧の版が必要な版以上で、保存済みの失効の和を包含すること）と通信は第8回で実装します。それまで、その端末は停止したままになります。

この文書は実機操作やAPK配布を指示するものではありません。実機の更新はオーケストレーターと利用者が行います。
